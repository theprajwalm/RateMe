# RateMe

**RateMe** is a Spring Boot web application for discovering and rating pubs in Zweibrücken.

The project was built to practice backend development, REST APIs, database design, and working with modern Java technologies.

## Features

* Create and manage pub ratings
* REST API for handling application data
* Persistent data storage with MySQL
* JPA/Hibernate for database access
* Docker setup for the database
* Basic separation of controllers, services, DTOs, and data access

## Tech Stack

**Backend:** Java 21, Spring Boot, Spring Data JPA
**Database:** MySQL
**Tools:** Maven, Docker, Git

## Running the Project

Clone the repository and start the application:

```bash
git clone https://github.com/theprajwalm/RateMe.git
cd RateMe
./mvnw spring-boot:run
```

The application runs on `http://localhost:8080`.
